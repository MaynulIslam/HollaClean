  With headed browser (watch it run):
  npx playwright test --headed

  Open HTML report after a run:
  npx playwright show-report

  UI mode (interactive test runner):
  npx playwright test --ui

  ▎ The config auto-starts npm run dev on localhost:3000 before tests run, so no need to start the dev server manually. Workers are set  
  to 1 (serial), so tests run one at a time in order.
